## ⭐ Best Discovery Today

- ReRead position in css
- Relative: can adjust with top, left, right, bottom but still in document flow
- Absolute: can adjust with top, left, right, bottom and not in document flow, depend on position of nearest parent
- Fixed: Like absolute but depend on position of viewport
- Sticky: relative + fixed; firstly relative but change to fixed when it hit the scroll position
