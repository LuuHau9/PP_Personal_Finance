## Key Takeaways

**Main concept learned:**

- Color format in web developer
  - RGB: color definition that's machine can understand
    - 0 -> 255: the brightness of three color red, blue, green in 1 pixel
    - Hard to understand for human
  - HSL: Hue, Saturation, Lightness.
    - Human understandable way.
    - Hard to make brightness consistent between different color
  - LCH: Lightness, Chroma, Hue
    - Include hsl benefit and respects how your eyes actually work. support modern brightness
